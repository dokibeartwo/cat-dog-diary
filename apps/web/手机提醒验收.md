# 手机网页前台提醒验收

2026-10-09。本次只更新手机网页，不替换 Windows 程序、不迁移或清空真实任务。

## 用户入口

设置 → 手机提醒设置 → 开启声音／可用震动 → 测试声音／震动。开关有选中颜色；音频处理时显示“正在启用声音…”，拒绝或超过约 2.5 秒未完成会给出可重试提示。点“体验大屏提醒”可查看实际页面覆盖层，通过“我知道了”关闭。

声音通过本次点击启用。重新打开页面或系统挂起音频后可能需要重新测试。设备震动接口接受请求不代表硬件已经振动，页面明确要求用户确认。iPhone Safari 不支持页面震动时开关禁用且原因可读；声音仍受媒体音量、静音、浏览器及系统设置影响。

设置同页提供 iPhone Safari 和安卓 Chrome 的主屏幕添加说明。图标继续使用现有小熊，六主题和背景不变。添加图标不等于后台推送或离线冷启动。

## 自动检查

- 11 项反馈控制器测试：默认关闭、仅保存设备布尔值、不支持／损坏设置、用户手势同步调用 resume、拒绝、超时、迟到结果、隐藏／换账号取消、自动提醒不强行解锁、去重、积压限频、延后／新发生、分区隔离、存储失败、跨标签停用和硬件拒绝。
- 8 项手机浏览器增量：不支持震动说明、开关与测试反馈、刷新持久化、重复 tick/数据刷新不重播、再次手动示例、音频拒绝／超时、切换分区取消迟到音频、隐藏与离席、总开关与勿扰、六主题360px与大字。
- 全量网页测试仍覆盖账号隔离、自动同步、提醒确认、延后、任务完成／删除、专注计时和原有布局。云请求及新增声音／震动 API 在浏览器自动测试中使用模拟，不读取真实账号会话，不发真实验证码。
- 静态构建继续通过白名单检查；不发布环境文件、备份、登录会话或任务数据库。

## 真机待确认

发布前独立副本已通过：48 项网页逻辑、5 项配置校验、36 项浏览器用例；构建、类型检查和 22 项静态文件白名单检查通过。新增勿扰测试使用覆盖当前时刻前后各一小时的时段，避免分钟末尾恰好越过测试边界。以下真机项目不包含在这些自动结果中。

1. iPhone Safari 开启声音，确认能听见短音；振动明确标为不支持。刷新后再点击测试；静音时不误报硬件声音成功。
2. 安卓支持的浏览器开启声音和震动，分别检查真实硬件效果；不能震动可换 Chrome，仍以本机表现为准。
3. 用不敏感测试任务设一个即将到期的提醒，保持前台，检查大屏及短提示，确认后不重复；修改／完成／删除时按既有规则更新。
4. 勿扰和离席期间普通事项静默，恢复后可处理提醒；专注完成、主动测试和已配置紧急穿透沿用原规则。
5. 切换 App 或锁屏期间不承诺提醒；返回页面重新核对真实时间，不连续补响积压队列。
6. 添加主屏幕小熊图标，点图标打开，必要时用同一邮箱登录并检查同步；不要求电脑开机。
