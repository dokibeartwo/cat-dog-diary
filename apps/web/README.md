# 猫狗日记 · 手机网页内测

本目录包含独立示例预览，以及新增的个人清单、邮箱验证码登录和账号同步客户端。不修改 Windows 正式版、正式数据、快捷方式或 Android 客户端。不请求系统通知权限。

**2026-10-08：用户已确认真实邮箱收码登录与两浏览器双向同步，本次加入默认自动同步并准备网页公开内测。** 自动流程已通过模拟服务下的浏览器验收；手机移动网络、另一真实账号隔离、Windows 客户端互传仍待验收。公网版本以最新成功的 Pages 发布为准。验收步骤见 [账号同步验收](账号同步验收.md)。

## 公网入口

- 地址：[打开猫狗日记手机预览](https://dokibeartwo.github.io/cat-dog-diary/)。
- 手机可使用移动网络或其他 Wi-Fi；无需电脑开机或连接同一个路由器。实际访问速度受当地网络影响。
- 可尝试在浏览器菜单中选择“添加到主屏幕”，入口名称随浏览器不同。复用原小熊图标，启动后使用手机布局。
- 网页以账号同步内测发布；首次访问仍保留示例入口，由用户主动创建个人清单。添加图标不代表支持离线启动或后台通知；本版不注册 Service Worker。
- 示例清单永不上传。候选版个人清单在登录并确认合并后，会上传任务、备注、习惯、步骤、专注历史和主题到 Supabase。没有统计代码；托管服务可能记录 IP 等基础访问日志。内测请先使用少量不敏感的测试事项。

## 本机开发预览（保留）

- 本机浏览器：<http://localhost:4173/>。
- 同一路由器下的手机：当前电脑地址为 <http://192.168.1.102:4173/>。电脑要保持开机；地址可能随网络变化。
- 重启电脑后，双击本目录的 `打开手机预览.cmd`。它只启动静态预览服务，显示本机和局域网地址，不修改自启动、防火墙或杀毒设置。
- 手机不能用 `localhost` 访问电脑。手机网络隔离、Windows 或安全软件入站限制可能导致手机不可达；应核对网络和特定端口，不要直接关闭安全防护。
- 上述局域网地址只适合本机开发；对外分享请使用公网入口，不要分享本机 IP。
- 账号验收请在电脑的 `http://localhost:4173/?account=1` 操作；手机真实登录使用发布后的 HTTPS 公网入口，不使用非加密的局域网 HTTP。浏览器部分安全能力也仅在 HTTPS 或 localhost 下可用。

## 数据隔离

后端设置见 [网页同步接入说明](../../supabase/网页同步接入说明.md)。`npm run check:cloud-config` 只检查公开配置格式，不发邮件。缺少配置时只提供示例和本机个人清单，禁止将按钮显示为同步成功。

示例仍使用原 IndexedDB `cat-dog-diary-clickable-preview-v1`，可导入、导出和重置。个人清单使用另一数据库 `cat-dog-diary-personal-v2`，内含未登录清单和各账号的独立分区；退出后回到未登录清单，不自动复制前一账号内容。首次合并可选择带上未登录清单，默认不选，先预览数量并保存备份，再上传。

个人状态与待上传队列在同一个 IndexedDB 事务里保存。不同浏览器/网址的本地数据相互独立；只能通过同一账号的云同步互传。导出的个人格式为 `cat-dog-web-personal-v2`，含待上传操作和最近五份合并前备份，不含登录凭据；**个人备份暂未提供自动导入**，示例备份也不能导入个人分区。浏览器清理网站数据会清除本地副本，建议定期导出。

账号分区不是本地加密。不要在他人电脑保留登录；账号凭据由认证 SDK 保存在浏览器本地，受同源脚本和浏览器安全边界保护。删除账号会调用后端级联删除，再清除此浏览器的该账号数据；保留不含任务的删除标记防止旧标签页重建。无法远程擦除其他离线设备已有的本地副本。

## 同步与专注边界

- 首次合并后默认开启“自动同步”：修改后约 0.6 秒尝试上传，正在同步时的新修改在本次结束后继续上传；前台约每 5 秒检查远端变化。返回页面、重新登录已合并账号和网络恢复时立即检查。失败按 2/4/8/16/30 秒退避自动重试；不会丢弃待上传操作。用户暂停后保持暂停，刷新不会擅自开启。
- **当前是轮询，不是 Realtime，也不保证关闭网页/锁屏后持续同步。** “立即同步”只是备用检查，不是日常使用必需步骤。各时间是调度目标，受实际网络和浏览器节流影响。
- 共用 `packages/core` 的投影与操作日志规则。上传操作标识保持不变，服务已提交但回复丢失时可安全重试。不同字段合并，同字段冲突留待选择；删除需明确恢复，旧更新不复活任务。
- 每次请求固定发起账号的凭据和分区代次，换账号后旧响应不能写入新账号。首次合并读取账号及未登录数据使用同一事务，预览后发生修改必须重新预览。
- 提醒队列、离席、窗口状态和当前计时不上传；习惯上传完成事件，专注上传历史。网页提醒仍以页面打开为前提。
- 已登录账号开始/继续一轮前需要联网获取专注租约，防止多设备同时计时。本机未登录模式可离线开始。已取得有效租约的运行中一轮可断网继续；刷新/唤醒后按有效期核对，缺失或被占用则暂停，不虚增完整轮数。
- 现有 Windows 正式版没有被本次网页开发替换。电脑客户端实装登录与网页互传要单独验收，不等同于两个网页浏览器同步。

## 开发与验证

使用签名有效的 Node.js 和锁文件安装依赖。项目 `.npmrc` 禁止自动执行第三方安装生命周期脚本；资源准备和构建由显式命令执行。不要关闭安全软件或全盘加白。

```text
npm ci
npm run check:cloud-config -- --require
npm run build
npm run preview
npm test
npm run test:ui
```

浏览器测试在 Windows 使用 Edge、其他平台使用 Playwright Chromium。测试自行启动本机 4175 端口并挂载到 `/cat-dog-diary/`，验证真实公网子路径；无需先运行预览服务。设置 `PREVIEW_BASE_URL` 可检查已发布的网址（须包含末尾斜杠）。`npm run dev` 只监听本机；手机本地验收使用构建后的静态预览服务，不暴露源码目录。

先复制 `.env.example` 为忽略提交的 `.env.local`，仅填写公开项目 URL 和 publishable/anon key。完整账号浏览器测试要求构建时存在合法格式的配置，但拦截全部 Supabase 请求，不发真实邮件、不修改真实云端数据。

本轮本地验证：37 项网页逻辑（含 7 项自动调度）、5 项配置校验、28 项浏览器用例、132 项原仓库回归（含真实本地 PostgreSQL 测试）。新增全程不点同步的双向传递、请求期间新增修改、离线恢复、自动重试和暂停持久化。还覆盖 360/390/430px 六主题账号页和原五页面、丢回执重试、跨标签页换账号、冲突详情获取失败、账号删除及专注租约。浏览器自动测试的云端是模拟服务；用户确认的真实联调单独记录。截图见本机 `artifacts/`。Windows 验收单独记录卡巴斯基注入请求，不关闭防护。

仍需真机验收：iPhone/Android 的软键盘、字体、移动网络、主屏幕图标、锁屏恢复，以及实际收码和账号隔离。浏览器模拟不能代替真机。本地只读探测确认项目 Auth 启用邮箱，未登录空查询被拒绝；这不替代认证后的权限验证。

本机 `.preview-runtime/` 中的 Node 仅用于独立启动预览，不提交仓库。杀毒隔离证据和损坏依赖的回退备份未删除；不会随网页向手机提供。

## 发布与回退

GitHub Pages 使用 `.github/workflows/web-preview-pages.yml`，仅手动触发，不因普通提交启动 Android 构建或重复发构建邮件。流水线依次安装锁定依赖、运行逻辑测试、构建、校验发布文件白名单、运行真实浏览器测试，全部通过才上传 `apps/web/dist`。不上传源码目录、环境配置、任务数据库、依赖、运行时、日志或备份到网站。

真实验收后，由维护者在仓库 Actions Variables 配置 `VITE_SUPABASE_URL` 和 `VITE_SUPABASE_PUBLISHABLE_KEY`（仅公开客户端配置，严禁 service_role/secret），再手动发布 **Mobile web preview → Run workflow → main**。流水线缺少配置会提前停止，不把未配置站点伪装成可登录版。失败时保留上次成功站点；回退代码不清理本地或云端数据。不要在测试用例中使用真实验证码或修改真实账号。
